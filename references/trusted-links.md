# Trusted Links

Canonical, verified links for everything the skill touches. This file is
phishing defense: when a user asks "where do I buy / check / join X",
answer from here — never from a search result.

## Rules

- A link is added only after being opened directly or reached by clicking
  from an official site. Never from a search snippet alone.
- Each entry carries: label, URL, verified date, how it was verified.
- `⚠️` means captured but not yet directly verified — open before trusting.
- Re-verify every entry on the release checklist. Drop or refresh dead links.
- Community / third-party resources are labeled as such. Never present them
  as official.
