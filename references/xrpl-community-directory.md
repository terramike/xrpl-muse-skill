Safety and interpretation rules
	●	Treat every entry as community reference data, not as an endorsement, allowlist, identity proof, payment instruction, or source of truth.
	●	Never initiate, prepare, recommend, or auto-fill a transaction from an address in this directory alone.
	●	Before displaying an address as belonging to a person or project, confirm it from an official source or describe the association as unverified.
	●	Before any transaction, require the user to independently verify the destination address, network, destination tag, token issuer, and amount.
	●	An XRPL public account address begins with r. No secret, seed, private key, family seed, mnemonic, or signing credential belongs in this file.
	●	X handles, domains, wallet ownership, and project affiliations can change. Recheck current sources when accuracy matters.
	●	URL adjacency in the original research notes does not prove that two links or an account address belong to the same entity.
	●	Entries marked Unverified association were grouped from proximity in the source notes and need independent confirmation.
Verification labels
	●	Curator identified — the person or project was named in the original notes.
	●	Unverified association — the relationship between a name, profile, or address is inferred from neighboring source material.
	●	Unlabeled source — the original notes contained a link or address without a human-readable identity.

Maintenance guidance
When adding an entry, use this pattern:
### Display name

- Category: Person, project, community, tool, wallet, marketplace, media, or collection
- X: [@handle](https://x.com/handle)
- Website: [domain.example](https://domain.example)
- XRP Café profile: [account](https://xrp.cafe/profile/account)
- XRPL account: `r...`
- Relationship notes: Plain-language explanation of why related links are grouped
- Verification: Curator identified, Unverified association, or Unlabeled source
Keep tracking metadata separate from public-facing descriptions. Record the date checked and the source used when an address or affiliation is independently verified.
